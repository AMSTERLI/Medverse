# Medverse Codebase

This repository contains code from **Medverse**.

## 🚀 Running the Demo

### 1. Environment Setup

Make sure you have Python and PyTorch installed. All required libraries are listed in the `requirements.txt` file. You can install them using:

```bash
pip install -r requirements.txt
```

### 2. Running the Demo Notebook

Open and run `demo.ipynb`. This notebook demonstrates how to use the model.

> ⚠️ **Note:** Due to the large size of the model, we are unable to upload the full model weights. Instead, we have included the model code only. In `demo.ipynb`, we use randomly generated tensors to showcase the model’s structure and usage.
